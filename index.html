01 — What it is

Built for agents.
Not humans.

Existing time trackers were built assuming a person clicks start and stop. Clawck assumes the opposite: your agents track themselves, automatically, with zero friction.

Drop it into any OpenClaw-compatible agent stack. Call clawck.start() when a task begins, clawck.stop() when it ends. That's it. Everything else — storage, API, dashboard — is handled.

Clawck is also the reference implementation for ClawckSpec: an open protocol for standardized AI agent time tracking, built to outlast any single framework.

agent-session.log

03 — The Standard
ClawckSpec

An open protocol
for agent time.

Time tracking for AI agents doesn't have a standard. Every framework does it differently — or doesn't do it at all. ClawckSpec changes that.

Think of it like OpenAPI for agent time: a shared schema for how timers start, stop, and report, so any tool in the ecosystem can speak the same language.

What the spec defines

  • Timer lifecycle events: start, stop, pause, resume
  • Agent identity fields on every entry
  • Task taxonomy and tagging conventions
  • Standard report aggregation shapes
  • Export formats compatible with billing systems
  • Minimum viable REST endpoint contract
